# Саҥа — якутская речь с нуля

Пет-проект по ML и речевым технологиям для якутского (саха) языка.
Идея: для малоресурсного языка нет больших корпусов, но есть лингвистические знания.
Проект превращает правила фонетики и морфологии в синтетическую речь, а на ней
обучает нейросетевое распознавание. Никаких предобученных моделей, датасетов
и фреймворков глубокого обучения — только numpy и scipy.

## Демо

Откройте `index.html` двойным кликом: это интерактивная страница, которая работает
прямо в браузере, без сервера и без Python. Вводите якутский текст, слушайте синтез
разными голосами, смотрите спектрограмму и запускайте распознавание; там же разбор
слова по слогам и падежам и графики обучения.

На GitHub: Settings → Pages → Source «Deploy from a branch», ветка `main`, папка `/ (root)`.
Через минуту страница откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

После переобучения страница пересобирается командой
`python3 web/export_tables.py && python3 web/build.py runs/pseudo` (результат в `web/sana.html`,
скопируйте его в `index.html`).

## Что внутри

| Модуль | Что делает |
|---|---|
| `sakha/phonology.py` | G2P (орфография → МФА): долгие гласные, дифтонги ыа/иэ/уо/үө, ҕ ҥ һ, дь/нь, геминаты; слогоделение; ударение на последнем слоге; проверка сингармонизма (ряд + огублённость) |
| `sakha/morphology.py` | Словоизменение с 4-вариантной гармонией и ассимиляцией: мн. число (оҕолор, аттар, күннэр, хаардар), дательный (акка, күҥҥэ, ынахха), винительный с озвончением (балыгы, ынаҕы), исходный, прошедшее время |
| `sakha/lexicon.py` | ~90 основ: существительные, глаголы, прилагательные, числительные |
| `sakha/synth.py` | Формантный синтезатор в духе Клатта: импульс Розенберга, 5 каскадных резонаторов, шумовая ветвь (Баттерворт), взрывы смычных, дрожащее р, коартикуляция, деклинация тона; параметрические «виртуальные дикторы» |
| `sakha/corpus.py` | Генерация фраз по шаблонам, аугментация (шум, реверберация, телефонная полоса), log-mel признаки |
| `sakha/nn.py` | Мини-фреймворк: dilated Conv1D, LayerNorm, residual-блоки, CTC-loss (forward-backward в лог-пространстве), Adam — все производные вручную |
| `train.py` | Обучение и оценка (CER/WER) |
| `tests/test_core.py` | CTC против полного перебора путей, численная проверка градиентов модели, тесты морфологии и фонологии |
| `web/` | JS-порт синтезатора и распознавателя, сборка интерактивной страницы |

## Запуск

```bash
python3 tests/test_core.py                       # проверки
python3 -c "from sakha.synth import *; save_wav('x.wav', synthesize('дорообо, саха тыла'))"
python3 train.py --n-train 16000 --epochs 25 --width 256
python3 web/export_tables.py && python3 web/build.py   # web/sana.html
```

## Эксперимент

* Обучение: 16 000 фраз, у каждой свой случайный диктор (мужской/женский/детский голос,
  длина тракта, темп, придыхание, джиттер), шум 5–40 дБ, эхо, телефонная полоса.
* Тесты (все дикторы новые):
  * **знакомые слова** — лексемы из обучения в новых комбинациях и формах;
  * **незнакомые слова** — 8 существительных, 2 прилагательных и 1 глагол, которые
    модель не слышала ни в одной форме (проверка, что она выучила звуки, а не слова);
  * **чистая запись** — без аугментации.
* Модель: 6 свёрточных слоёв, dilation 1-1-2-2-4, ширина 256, ~1.7 млн параметров;
  посимвольный CTC, жадное декодирование.

### Результаты (CER / WER)

| Тест | Только словарь (`runs/main`) | Словарь + 50% псевдослов (`runs/pseudo`) |
|---|---|---|
| Знакомые слова, новые дикторы, шум | 0.1% / 0.7% | 0.6% / 3.9% |
| **Незнакомые слова** | **17.3% / 74.0%** | **1.2% / 7.2%** |
| Чистая запись | 0.0% / 0.2% | 0.2% / 2.0% |

Главный вывод: первая модель в основном запомнила 90 слов словаря. Когда половину
корпуса заменили на несуществующие, но фонотактически правильные слова (слоги по
правилам якутского, гармония гласных, настоящие аффиксы — `corpus.pseudo_word`),
ошибка на незнакомых словах упала в 14 раз. Обучение каждой модели — ~30 минут
на 2 ядрах CPU.

```bash
python3 train.py --n-train 16000 --epochs 25 --width 256 --pseudo 0.5 --out runs/pseudo
```

## Ограничения

Модель не слышала живых людей и на реальной речи работать не будет: формантный голос
намного беднее живого. Следующий шаг — использовать синтетику как предобучение
и дообучить на якутской части Mozilla Common Voice.
